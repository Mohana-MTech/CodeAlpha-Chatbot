# CodeAlpha-Chatbot

## 📖 Project Overview
- Internship Task 2 under CodeAlpha.
- Simple chatbot built in Python.
- Responds to greetings and basic queries.
- Ends conversation when user types "bye".
- Demonstrates keyword matching and basic NLP concepts.

##  Execution Guide
I used **Visual Studio Code** to run this project:
1. Saved the file as `chatbot.py`.
2. Opened the integrated terminal (`View → Terminal`).
3. Executed the program with:
   python chatbot.py
